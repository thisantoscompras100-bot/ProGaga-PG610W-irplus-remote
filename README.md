# ProGaga PG610W (Whale TV / MT9269) - irplus IR Remote Profile

Custom XML infrared remote control layout for the **ProGaga PG610W** projector using the `WINLIRC_NEC1` protocol for the **irplus** Android app.

Because this projector model (and similar Whale TV / MediaTek MT9269 white-label projectors) is not included in standard IR databases, all remote buttons were manually mapped and tested on a **POCO X8 Pro Max**.

## Mapped Buttons / Botões Mapeados
- **Power** & **Mute**
- **Source** (HDMI / USB / AV) & **Settings**
- **Navigation:** Up, Down, Left, Right, OK, Back, Home, Menu
- **Audio:** Volume +, Volume -
- **Image:** Focus / Keystone adjustments

## How to Use / Como Usar
1. Download the `.irplus` (`.xml`) file from this repository.
2. Install **irplus** on an Android smartphone equipped with an IR Blaster.
3. Open **irplus**, open the side menu, and select **Import**.
4. Choose the downloaded file and start controlling your projector.
